Attendance Device Verification

Bind employees to their phones/laptops via WebAuthn (fingerprint / Face ID) to prevent proxy attendance.

{% csrf_token %}
Enable Device Verification
When enabled, employees must register their device before clocking in/out. Requires HTTPS in production.
Device Limits Per Employee
Allow 1–5 phones per employee
Allow 1–5 laptops/desktops per employee
Behavior Settings
Notify HR on New Device
Send a notification when an employee registers a new device
Allow HR Override / Reset
Let HR admin manually reset or override device verification for any employee
Allow Employee Self-Removal
Let employees remove their own secondary devices from profile
Allow Office IP Fallback
If device verification fails, allow clock-in from office IP as backup
Require HR Approval for New Devices
When enabled, new device registrations must be approved by HR before the employee can clock in/out. Highly recommended for security.
HTTPS required in production. WebAuthn works on localhost for testing and on https:// domains in production. Devices are registered per browser/device — Chrome, Firefox, and Safari each count as separate devices.
How It Works
1
First Clock-In
Employee clocks in → browser prompts for fingerprint / Face ID → device is registered against their account.
2
Subsequent Clock-Ins
Employee's device fingerprint is verified automatically — no password or manual step needed.
3
Prevents Proxy Attendance
If another employee tries to use the credentials on a different device, the WebAuthn check fails → attendance blocked.
